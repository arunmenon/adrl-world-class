# EVL — Evaluation, Graduation, Rollout

Not captured in the source pack. Known by cross-reference only: EVL-004 (label quantity/quality threshold for retrieval authority), EVL-005 (simulator evidence is not organic evidence), EVL-006/007 (offline evaluation against baselines and explicit human graduation), EVL-009 (blockers are never averaged away).

The 2026-09-02 review touches EVL in three places: LRN-002/LRN-007 require that "offline evaluation" of a routing artifact be branched or propensity-weighted, never replay; RTG-007 assigns the pre-build gate to EVL; and every metric must report its excluded fraction as a representativeness condition (Q6). These should be folded into the EVL page when it is captured.
